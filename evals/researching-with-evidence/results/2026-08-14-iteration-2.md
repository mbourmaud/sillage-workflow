# Researching with evidence — iteration 2

## Environment

- Date: 2026-08-14
- Runtime: Codex agent comparison
- Prompt set: `../evals.json`
- Human review: accepted for the 0.1.0 release candidate

## Result

The initial skill preserved source authority and durable-knowledge promotion,
but produced an unnecessarily large empty evidence packet when the research
subject was missing. The revised instruction asks one focused question and
stops; eval 3 confirmed that behavior.

The controlled Orbit Retry fixture confirmed that the skill:

- resolved the installed 2.4.0 version;
- preferred installed implementation and matching official documentation;
- rejected a contradictory tutorial claim;
- separated research-backed recommendation from approval;
- promoted only the stable adapter invariant, not raw notes.

The no-skill baseline also reached the correct conclusion and was more concise.
The current evidence therefore supports consistency and artifact-lifecycle
guidance, not a claim that the skill universally outperforms a capable baseline.

The first external installation pilot then loaded
`sillage-workflow@0.1.0-rc.1` through the Codex marketplace and activated this
skill in a fresh task. The result followed the evidence-packet contract, used
primary sources, separated fact from inference, and created no repository
document. The human maintainer accepted the pilot on 2026-08-14.
