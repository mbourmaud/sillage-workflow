# Working with Sillage — pilot

## Environment

- Date: 2026-08-14
- Runtime: Codex desktop task, Go 1.25.5, `skills` CLI 1.5.22 on Node 24.19.0
- Source: `mbourmaud/sillage-workflow` main line
- Skill: `working-with-sillage`, installed globally from the Sillage repository
- Prompt: continue the full Sillage workflow and make it ready for user testing

## Scope

This pilot covers the smallest useful onboarding slice: expose the complete
workflow skill, document deliberate updates, and run the deterministic full
workflow example. It does not publish a new version, merge a pull request, or
claim independent behavioral superiority over a no-skill baseline.

## Stages observed

- **INTAKE:** bounded the request to full-workflow onboarding and pilotability.
- **INVESTIGATE:** read the product, design, agent, domain, profile, existing
  skill, plugin bundle, evaluation fixtures, and release docs.
- **DECIDE:** preserved the candidate status until independent evaluation and
  human review exist; no product or release scope was invented.
- **IMPLEMENT:** added the `make pilot` path, lifecycle contract assertion, and
  install/update guidance.
- **VERIFY:** ran `make check`, `make pilot`, and `npx skills update
  working-with-sillage --global --yes`.
- **REVIEW:** checked canonical/bundled skill parity and kept the change
  limited to onboarding, pilotability, and evaluation traceability.
- **HANDOFF:** left the result in PR #5; merge and release remain human gates.

## Evidence

- `make check` passed, including Go tests, race tests, actionlint, contracts,
  changelog validation, site validation, and project doctor.
- `make pilot` passed the project doctor, context/status views, explicit
  transition write, and resulting `HANDOFF` status on a temporary task copy.
- The skills CLI reported both Sillage skills as globally installed from
  `mbourmaud/sillage-workflow` and reported `working-with-sillage` up to date.

## Limits and next gate

This is a pilot record, not the release evaluation: it contains no separate
fresh-context no-skill baseline and no independent human qualitative grading.
Run those two comparisons before changing `evals/working-with-sillage/evals.json`
from `draft` or calling the orchestration skill released.
