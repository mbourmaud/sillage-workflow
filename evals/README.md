# Skill evaluations

Each skill owns realistic prompts and comparison evidence. Baseline and
with-skill runs use the same prompt in fresh contexts. Objective assertions
cover observable contract requirements; human review remains authoritative for
clarity, usefulness, and unnecessary ceremony.

Generated evaluation workspaces are ignored by Git. Published summaries must
state the model/runtime, date, prompt set, known limitations, and whether the
baseline genuinely exhibited the failure the skill claims to correct.
