# Skill evaluations

The router suite owns realistic prompts for lifecycle routing and specialist
lenses. Baseline and with-skill runs use the same prompt in fresh contexts.
Objective assertions cover observable contract requirements; human review
remains authoritative for clarity, usefulness, correct restraint, and
unnecessary ceremony.

Generated evaluation workspaces are ignored by Git. Published summaries must
state the model/runtime, date, prompt set, known limitations, and whether the
baseline genuinely exhibited the failure the skill claims to correct. Do not
mark the suite released merely because frontmatter or substring tests pass.
